# Исполнительная документация ПТО

## Состав исполнительной документации (ИД)

Согласно СНиП 12-01-2004, РД-11-02-2006:

### Обязательные документы ИД

1. **Акты освидетельствования скрытых работ (АОСР)**
   - Разбивка осей
   - Арматурные работы (до бетонирования)
   - Прокладка коммуникаций в земле
   - Гидроизоляция
   - Теплоизоляция трубопроводов

2. **Исполнительные схемы** (основная задача ПТО)
   - Геодезическая исполнительная съёмка
   - Схемы прокладки подземных коммуникаций
   - Схемы монтажа конструкций с фактическими отметками
   - Схемы систем ОВ, ВК, ЭО

3. **Журналы работ**
   - Общий журнал работ (ОЖР)
   - Журнал бетонных работ
   - Журнал сварочных работ
   - Журнал геодезического контроля

4. **Сертификаты и паспорта** на применённые материалы

## Состав исполнительной схемы

### Требования к оформлению (РД-11-02-2006)

**Обязательные элементы чертежа:**
- [ ] Угловой штамп (по ГОСТ 21.101)
- [ ] Масштаб
- [ ] Привязки к постоянным ориентирам (оси здания, реперы)
- [ ] Фактические размеры и отметки (подчёркнутые или в рамке)
- [ ] Проектные размеры (для сравнения)
- [ ] Отклонения (если превышают допуск — выделить)
- [ ] Подпись геодезиста / инженера ПТО
- [ ] Дата съёмки

### Допускаемые отклонения (типовые)

| Вид работ | Допуск |
|-----------|--------|
| Оси фундаментов | ±10 мм |
| Отметки фундаментов | ±20 мм |
| Стены монолитные (вертикаль) | 1/500 высоты, но ≤15 мм |
| Трубопроводы (уклон) | ±0.001 от проектного |
| Кабельные трассы | ±50 мм от оси |

## Workflow подготовки исполнительной схемы в AutoCAD

### Шаг 1: Подготовка шаблона
```
1. Открыть базовый чертёж из проекта (DWG)
2. Создать новый слой "ИСПОЛН_ФАКТ" (цвет красный/жёлтый)
3. Заморозить/скрыть лишние слои
```

### Шаг 2: Нанесение фактических данных
```
1. Оси разбивки — проверить привязку к реперам
2. Фактические контуры — на отдельном слое
3. Отметки — текстом с подчёркиванием (фактические)
4. Размеры — dimlinear на слое РАЗМЕРЫ
```

### Шаг 3: Оформление
```
1. Заполнить штамп (дата, подписи, шифр)
2. Добавить примечания об отклонениях
3. Распечатать в масштабе на формате
4. Подписать у геодезиста
```

### Шаг 4: Архивирование
```
1. Сохранить DWG в папку ИД проекта
2. Экспортировать PDF (команда EXPORTPDF)
3. Передать в архив с реестром
```

## Типичные ошибки в ИД (чек-лист)

- [ ] Отсутствует масштаб на схеме
- [ ] Не подписан геодезист
- [ ] Фактические отметки не отличаются от проектных визуально
- [ ] Нет привязки к репперу / оси
- [ ] Дата съёмки не совпадает с АОСР
- [ ] Штамп не заполнен (пустые поля)
- [ ] Чертёж выполнен от руки без CAD (не допускается для сдачи в Госстройнадзор)
- [ ] Нет подписи «Фактическое положение» / «Проектное положение»
