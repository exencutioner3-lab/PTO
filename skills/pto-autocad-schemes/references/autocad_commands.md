# Шпаргалка команд AutoCAD для ПТО

## Основные команды

| Команда | Алиас | Описание |
|---------|-------|----------|
| `LINE` | `L` | Отрезок |
| `PLINE` | `PL` | Полилиния |
| `CIRCLE` | `C` | Окружность |
| `ARC` | `A` | Дуга |
| `RECTANGLE` | `REC` | Прямоугольник |
| `OFFSET` | `O` | Параллельное смещение |
| `TRIM` | `TR` | Обрезка |
| `EXTEND` | `EX` | Удлинение |
| `MIRROR` | `MI` | Зеркало |
| `COPY` | `CO` | Копирование |
| `MOVE` | `M` | Перемещение |
| `ROTATE` | `RO` | Поворот |
| `SCALE` | `SC` | Масштаб |
| `ARRAY` | `AR` | Массив |
| `HATCH` | `H` | Штриховка |
| `MTEXT` | `MT` | Многострочный текст |
| `DTEXT` | `DT` | Однострочный текст |
| `DIMLINEAR` | `DLI` | Линейный размер |
| `DIMALIGNED` | `DAL` | Выровненный размер |
| `DIMRADIUS` | `DRA` | Размер радиуса |
| `LEADER` | `LE` | Линия-выноска |
| `BLOCK` | `B` | Создание блока |
| `INSERT` | `I` | Вставка блока |
| `WBLOCK` | `W` | Запись блока в файл |
| `XREF` | `XR` | Внешние ссылки |
| `LAYER` | `LA` | Управление слоями |
| `PROPERTIES` | `PR` | Свойства объекта |
| `MATCHPROP` | `MA` | Перенос свойств |
| `PEDIT` | `PE` | Редактирование полилинии |
| `EXPLODE` | `X` | Разбивка блока/полилинии |
| `JOIN` | `J` | Соединение объектов |
| `FILLET` | `F` | Сопряжение |
| `CHAMFER` | `CHA` | Фаска |
| `ATTEDIT` | `ATE` | Редактирование атрибутов |
| `ATTDEF` | `ATT` | Определение атрибута |

## Управление видами и листами

| Команда | Описание |
|---------|----------|
| `LAYOUT` | Создание/управление листами |
| `MVIEW` | Создание видового экрана |
| `VPORTS` | Управление видовыми экранами |
| `ZOOM` | Масштаб вида (E — экстенты, W — рамка) |
| `PAN` | Прокрутка вида |
| `REGEN` | Регенерация чертежа |
| `REGENALL` | Регенерация всех видов |
| `PURGE` | Очистка от неиспользуемых объектов |
| `AUDIT` | Проверка целостности файла |
| `RECOVER` | Восстановление повреждённого файла |

## Привязки (OSNAP)

| Код | Привязка |
|-----|----------|
| `END` | К конечной точке |
| `MID` | К середине |
| `CEN` | К центру |
| `INT` | К пересечению |
| `PER` | Перпендикуляр |
| `TAN` | Касательная |
| `NEA` | К ближайшей точке |
| `NOD` | К узловой точке |

## Экспорт и печать

```
PLOT          — диалог печати
EXPORTPDF     — экспорт в PDF
PUBLISH       — пакетная публикация листов
PAGESETUP     — настройка страницы
PLOTTERMANAGER — управление плоттерами
```

## Полезные системные переменные

| Переменная | Рекомендуемое значение | Описание |
|------------|------------------------|----------|
| `LTSCALE` | 100–1000 | Масштаб типов линий |
| `DIMSCALE` | = масштаб чертежа | Масштаб размерного стиля |
| `TEXTSIZE` | 2.5–5 | Высота текста по умолчанию |
| `MIRRTEXT` | 0 | Текст не зеркалится |
| `PICKFIRST` | 1 | Выбор до команды |
| `OSMODE` | 4135 | Режимы привязки |
| `LUNITS` | 2 | Десятичные единицы |
| `LUPREC` | 0–2 | Точность отображения |
| `ANGBASE` | 0 | Начальный угол (восток) |
| `ANGDIR` | 0 | Направление углов (против часовой) |
