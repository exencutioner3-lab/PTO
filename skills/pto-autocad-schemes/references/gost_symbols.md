# Условные обозначения трубопроводов (ГОСТ 21.205-2021)

## Трубопроводы — типы линий

| Система | Линия | Обозначение |
|---|---|---|
| Подача теплоносителя (Т1) | толстая сплошная | ────────── |
| Обратка теплоносителя (Т2) | толстая штриховая | ── ── ── |
| Холодное водоснабжение (Х) | сплошная | ────────── |
| Горячее водоснабжение (ГВС) | сплошная с меткой | ──●──●── |
| Канализация самотёчная | сплошная со стрелкой | ──→──→── |
| Пар | двойная сплошная | ══════════ |
| Конденсат | двойная штриховая | ══ ══ ══ |
| Технологический трубопровод | с буквенным индексом на линии | |
| Подземный трубопровод | скрытая линия | ─ ─ ─ ─ |
| Направление потока | стрелка на линии | ──►── |

## Арматура трубопроводная (ГОСТ 21.205-2021)

> Обозначения обновлены 15.10.2026 по реальному чертежу пользователя.

| Наименование | Вид на чертеже | Описание формы | Применение |
|---|---|---|---|
| **Кран шаровой** | `─▷◁─` | **два треугольника вершинами навстречу (бабочка)** | ВК, ВС, ОВ, ТХ |
| **Задвижка** | `─┤├─` | два вертикальных штриха со скобками | ТС, ТМ, ВК |
| **Вентиль запорный** | `─▽─` | треугольник вершиной вниз | ОВ, ВС, ТХ |
| **Клапан обратный** | `─▷‖─` | треугольник + вертикаль | ВК, ВС, ТС |
| **Клапан предохр.** | `─▽↑─` | треугольник + патрубок вверх | ТМ, ТС, ТХ |
| **Клапан регулир.** | `─▷◁─` + привод | бабочка + кружок с буквой (M/Э/П) | ОВ, ТС (ИТП) |
| **Балансировочный** | `─▷◁─` + `∅` | бабочка + метка настройки | ОВ |
| **Фильтр сетчатый** | `─┤Y├─` | косой треугольник в корпусе | ВК, ТС, ОВ |
| **Расходомер** | `─⊙─` | кружок с точкой/крестом | ТС, ТХ, ВС |
| **Манометр** | `/── ○M` | выноска → кружок с буквой M | ТС, ТМ, ТХ |
| **Термометр** | `/── ○T` | выноска → кружок с буквой T | ТС, ТМ |
| **Воздухоотводчик авт.** | `↑A` на трубе | стрелка вверх + A | ОВ, ТС |
| **Воздухоотводчик руч.** | `↑` на трубе | стрелка вверх | ОВ |
| **Дренаж** | `↓` на трубе | стрелка вниз | ОВ, ТС, ТМ |
| **Фланец** | `─║─` | двойная вертикальная черта | все |
| **Заглушка** | `─║●` | вертикаль + закрашенный круг | все |
| **Компенсатор П-образный** | `─⊓─` | П-образный изгиб | ТС надземные |
| **Компенсатор сальниковый** | `─⊏⊐─` | два прямоугольника | ТС подземные |

## Маркеры на трубопроводах (ГОСТ 21.205, из чертежей пользователя)

| Элемент | Вид | Описание |
|---|---|---|
| **Номер стыка** | `● ─── ст.1` | закрашенный кружок Ø3–4 мм + горизонтальная полка + текст `ст.N` |
| **Позиция по спецификации** | `/ ─── [45]` | наклонная линия + горизонталь + прямоугольник с номером |
| **Опора неподвижная** | `──✳──` | звезда (перекрещённые диагонали) поперёк трубы |
| **Опора скользящая** | `──═══──` | двойная параллельная линия поперёк трубы |
| **Направление потока** | `──►──` | стрелка на линии трубопровода |

### Схема нанесения маркеров

```
НОМЕР СТЫКА:
                  ст.1
  ─────────●──────────
  (кружок в точке стыка сварного шва)

ПОЗИЦИЯ ПО СПЕЦИФИКАЦИИ:
       [45]
   ────┘
  /           (наклонная линия от объекта → горизонталь → рамка с номером)

ОПОРА НЕПОДВИЖНАЯ:
       │
  ─────✳─────     (звезда поперёк трубы, фиксация от осевого смещения)
       │

ОПОРА СКОЛЬЗЯЩАЯ:
      ═══
  ─────────────   (двойная черта поперёк, труба скользит вдоль оси)
      ═══
```

## Оборудование тепломеханики (ТМ / ТС / ТХ)

| Оборудование | Обозначение |
|---|---|
| Насос центробежный | `(Н)` в кружке со стрелкой направления |
| Насос с электродвигателем | `(НМ)` |
| Теплообменник кожухотрубный | прямоугольник с диагоналями |
| Теплообменник пластинчатый | прямоугольник со штриховкой |
| Расширительный бак | `(РБ)` |
| Гидравлический разделитель | вертикальный цилиндр `(ГР)` |
| Бойлер / ёмкость ГВС | вертикальный цилиндр `(Б)` |

## Маркировка трубопроводных линий

### Буквенно-цифровая марка на плане/аксонометрии

```
  Т1-1         — подача, линия №1
  Т2-1         — обратка, линия №1
  Х-1          — холодная вода, стояк №1
  ГВС-1        — горячая вода, стояк №1
  К1-1         — канализация бытовая, стояк №1
  К2-1         — канализация ливневая
  П-1          — пар, линия №1
  К-1          — конденсат, линия №1
```

### Обозначение диаметра на линии

```
  Ду100        — условный диаметр 100 мм
  Ø108×5       — наружный Ø и толщина стенки
  DN100/PN16   — международная форма
```

### Высотные отметки трубопроводов

```
  ▽ +0.000     — отметка лотка трубы (ниже оси)
  ∅ +0.000     — отметка оси трубы
  ▲ +0.000     — отметка верха трубы (верх изоляции)
  (i=0.002)    — уклон участка
```

## Обозначения на схемах ВК (внутренние сети)

| Элемент | Обозначение |
|---|---|
| Стояк В1 (хол. вода) | `Ст.В1-1` в кружке |
| Стояк Т3 (горяч. вода) | `Ст.Т3-1` в кружке |
| Стояк К1 (канализация) | `Ст.К1-1` в кружке |
| Ревизия | прямоугольник на стояке |
| Прочистка | `П` на стояке |
| Водомерный узел | `ВУ` |
| ИТП (тепловой пункт) | прямоугольник `ИТП` |
| Насосная станция | `НС` |

## Обозначения на схемах ТС (тепловые сети наружные)

| Элемент | Обозначение |
|---|---|
| Камера тепловая | прямоугольник `ТК-№` |
| Узел пересечения | кружок с меткой |
| Ввод в здание | стрелка с пересечением линии фасада |
| Неподвижная опора | `▲` на трубопроводе |
| Компенсатор | `⊓` или `⊏⊐` |
| Перемычка | пунктир с `П` |
