# ПТО — Подсчёт объёмов по трубопроводным разделам (ТХ / ВК / ВС / ОВ / ТК / ТМ / ТС)

---

## 1. Ведомость объёмов работ (ВОР) — структура

| № | Наименование работ | Ед. изм. | Кол-во | Примечание |
|---|---|---|---|---|
| 1 | Прокладка трубопровода Ду___ | м пог. | ... | материал, система |
| 2 | Установка арматуры Ду___ | шт. | ... | тип, Ру |
| 3 | Изоляция трубопровода Ду___ | м пог. | ... | тип, толщина |
| 4 | Монтаж оборудования | шт. | ... | наименование |
| 5 | Испытание трубопровода | м пог. | ... | гидравлическое |
| 6 | Промывка системы | м пог. | ... | ВК, ВС, ОВ |

### Единицы измерения

| Вид работ | Ед. изм. |
|---|---|
| Трубопроводы (все виды) | м пог. |
| Арматура (задвижки, краны, клапаны) | шт. |
| Компенсаторы | шт. |
| Фланцевые соединения | шт. (пара) |
| Сварные стыки | шт. |
| Опоры, подвески | шт. |
| Изоляция трубопровода | м пог. или м² |
| Оборудование (насосы, теплообменники) | шт. |
| Испытание трубопровода | м пог. |
| Промывка | м пог. |
| Дезинфекция (ВС питьевая) | м пог. |

## 2. Формулы подсчёта

### Длина трубопровода

```
L = Σ участков по аксонометрии или плану
  + запас на монтаж: +2% от общей длины (фитинги, подрезка)

Из AutoCAD:
  QSELECT → Layer = нужный слой → Properties → суммарная длина
  Или команда ДЛИНА-СЛОЯ (LISP из lisp_snippets.md)
```

### Масса трубопровода (сталь)

```
M [кг] = L × m_пог
M [т]  = M [кг] / 1000

Справочник погонной массы стальных труб (ГОСТ 8732 / 10704):
```

### Площадь изоляции трубопровода

```
S [м²] = L × π × (D_нар/1000 + δ_из)
где:
  D_нар — наружный диаметр трубы, мм
  δ_из  — толщина изоляции, м (обычно 0.05–0.12 м)

Упрощённо (δ << D):
  S ≈ L × π × D_нар / 1000
```

### Количество сварных стыков

```
N_стыков = N_секций - 1 + N_вставок + N_фитингов_под_сварку
Ориентировочно: 1 стык на 6–12 м трубы (в зависимости от мерной длины)
```

### Количество фланцевых соединений

```
N_фланц = 2 × N_фланцевой_арматуры + N_разборных_соединений_с_оборудованием
```

## 3. Спецификация оборудования и материалов (ГОСТ 21.110-2013)

### Форма спецификации

```
Поз. | Обозначение  | Наименование                  | Кол. | Масса | Примечание
-----|--------------|-------------------------------|------|-------|----------
  1  | ГОСТ 356-80  | Задвижка 30с41нж Ду100 Ру16   | 2 шт | 18 кг | фланц.
  2  | ГОСТ 8732-78 | Труба 108×5 ст.20             | 45 м |  —   |
  3  | ТУ 28-08     | Отвод 90° Ду100 Ру16          | 6 шт |  —   |
```

### Порядок составления

1. Выбрать все трубопроводы с чертежа → подсчитать длины по Ду
2. Выбрать всю арматуру → занести позиционно
3. Фитинги (отводы, тройники, переходы) → по чертежу
4. Опоры, подвески → по чертежу
5. Изоляция → рассчитать по формуле (раздел 2)
6. Оборудование → из экспликации

### 3.1 Таблицы участков трубопроводов и строки итогов (ТС, ТМ, ТХ)

На листах схем тепловых сетей и трубопроводов размещаются таблицы участков вида:

```
┌─────────┬───────────┐
│ Участок │ Длина, мм │
├─────────┼───────────┤
│ 1 - 2   │ 15400     │
│ 2 - 3   │ 8200      │
│ ...     │ ...       │
├─────────┴───────────┤
│ Итого: монтаж трубопровода+фасонные изделия   │ 43005 │
├───────────────────────────────────────────────┤───────┤
│ Итого: Общая протяженность участка линии      │ 43755 │
└───────────────────────────────────────────────┴───────┘
```

> [!IMPORTANT]
> **Утверждённый стандарт формулировок итоговых строк:**
> - Строка 1: `Итого: монтаж трубопровода+фасонные изделия` (чистый монтаж труб с учётом фасонины)
> - Строка 2: `Итого: Общая протяженность участка линии` (суммарная строительная протяженность трассы)
>
> **Если в чертеже старая формулировка:**
> - Если 1-я строка: «Итого: монтаж трубопровода» → заменить на `Итого: монтаж трубопровода+фасонные изделия`
> - Если 2-я строка: «Итого: монтаж трубопровода+фасонные изделия» → заменить на `Итого: Общая протяженность участка линии`
> Для быстрой пакетной замены на всех листах чертежа использовать DXF-пайплайн из скилла `pto-autocad-schemes`.

#### Методика заполнения таблицы «Интервалы между стыковыми соединениями»:
1. **Строка прямого участка** (например, `48-49`): вносится геометрическая длина трубы из чертежа (мм).
2. **Строка фасонного элемента** (например, `47-48 (отвод)`, `34-35 (переход)`): вносится строительная длина $F$ или $L$ из таблицы выше (мм).
3. **Строка «Итого: Монтаж трубопровода+фасонные элементы»**: сумма длин всех участков + длин всех фасонных элементов (мм).
4. **Строка «Итого: Общая протяженность участка линии»**: суммарная строительная длина трубопровода линии по спецификации (соответствует объёму труб в спецификации в миллиметрах).

## 4. Подсчёт в AutoCAD

### Длина трубопроводов по слою

```
Команда в AutoCAD:
1. QSELECT → тип объекта: Полилиния, слой: ТС-Т1 → OK
2. Открыть Properties → поле "Суммарная длина"

Или LISP-команда ДЛИНА-СЛОЯ (из references/lisp_snippets.md):
  вводишь имя слоя → получаешь суммарную длину в единицах чертежа
```

### Подсчёт арматуры (блоков INSERT)

```
QSELECT → тип объекта: Вхождение блока → Имя блока = нужный блок
→ Properties → Count (количество)
```

## 5. Типичные нормы расхода (ориентир)

| Показатель | Значение |
|---|---|
| Потери трубы на монтажные нужды | 2–3% от общей длины |
| Прокладки фланцевые на 1 фланец | 1 шт. |
| Болты на фланец Ду100 | 8 шт. М16×70 |
| Болты на фланец Ду150 | 8 шт. М16×80 |
| Болты на фланец Ду200 | 12 шт. М20×90 |
| Электроды на 1 кг наплавленного металла | ~1.6 кг |

## 6. Workflow подготовки ВОР

```
1. Получить РД (рабочую документацию) — DWG или PDF
2. Для DWG: подсчитать длины труб через QSELECT или ДЛИНА-СЛОЯ
3. Разбить по Ду и разделам (ВК, ОВ, ТС...)
4. Подсчитать арматуру по позициям
5. Рассчитать изоляцию по формуле
6. Заполнить ВОР в Excel (форма — раздел 1)
7. Передать в сметный отдел (ТЕР/ФЕР раздел «Трубопроводы»)
```
