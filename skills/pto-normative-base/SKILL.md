## 2. Допуски монтажа трубопроводов

### Общие допуски (ГОСТ 21.205, СП 75.13330)

| Параметр | Допуск |
|---|---|
| Отклонение оси трубопровода от проектного положения | ±50 мм |
| Уклон самотёчной канализации | не менее расчётного (i_min по СП 30) |
| Уклон самотёчной ливневой канализации | не менее 0.001 |
| Отклонение отметки лотка трубы | ±10 мм |
| Смещение фланцевых соединений | не более 1 мм на Ду |

### Тепловые сети ТС (СП 74.13330)

| Параметр | Допуск |
|---|---|
| Смещение оси трубы от проектной | ±100 мм (подземные), ±50 мм (надземные) |
| Отклонение отметки верха трубы | ±50 мм |
| Глубина заложения от проекта | ±100 мм |
| Расстояние между опорами | по проекту ±5% |

### Внутренние системы ОВ и ВК (СП 60, СП 30)

| Параметр | Допуск |
|---|---|
| Уклон горизонтальных труб отопления | ≥0.002 (к расширительному баку) |
| Уклон холодной воды | ≥0.002 (к водоразбору) |
| Уклон канализации Ду50 | ≥0.035 |
| Уклон канализации Ду100 | ≥0.020 |
| Уклон канализации Ду150 | ≥0.010 |
| Отклонение стояка от вертикали | ≤2 мм на 1 м, ≤10 мм на всю высоту |

### Технологические трубопроводы ТХ (ГОСТ 32569)

| Категория | Рабочее давление | Испытательное давление |
|---|---|---|
| I | >10 МПа | 1.5 × рабочее, но ≥0.2 МПа |
| II | 1.6–10 МПа | 1.5 × рабочее |
| III | 0.07–1.6 МПа | 1.5 × рабочее |
| IV | ≤0.07 МПа | 1.25 × рабочее, но ≥0.2 МПа |

## 3. Испытания трубопроводов

### Гидравлические испытания (общий порядок)

1. Заполнить систему водой, удалить воздух
2. Поднять давление до испытательного
3. Выдержка: **10 минут** (ВК, ОВ), **30 минут** (ТС, ТМ, ТХ)
4. Снизить до рабочего, осмотреть
5. Составить Акт гидравлического испытания

**Испытательное давление:**

| Система | P_исп |
|---|---|
| ОВ, ВК (внутренние) | 1.5 × рабочее, но ≥0.6 МПа |
| Тепловые сети ТС | 1.25 × рабочее, но ≥1.6 МПа |
| Холодное водоснабжение | 1.5 × рабочее, но ≥1.0 МПа |
| Канализация (пролив) | пролив — не давление |

### Промывка / продувка

| Тип | Система | Требования |
|---|---|---|
| Промывка водой | ВК, ВС, ОВ, ТС | до осветления воды |
| Дезинфекция | ВС (хозпитьевая) | хлорирование, смыв, бактериология |
| Продувка воздухом | ТХ, ТМ | по регламенту проекта |

## 4. Состав ИД по трубопроводным разделам

### Обязательные документы (РД-11-02-2006)

- [ ] Комплект рабочих чертежей с отметкой «В производство работ»
- [ ] АОСР: прокладка трубопровода (до засыпки / закрытия)
- [ ] АОСР: изоляция трубопровода
- [ ] АОСР: антикоррозионное покрытие
- [ ] АОСР: испытание трубопровода (гидравлическое)
- [ ] АОСР: промывка / дезинфекция (ВС)
- [ ] Акт гидравлического (пневматического) испытания
- [ ] Исполнительные схемы (план, разрез, аксонометрия — факт)
- [ ] Паспорта, сертификаты: трубы, арматура, фитинги, теплоизоляция
- [ ] Протокол промывки / дезинфекции (ВС)
- [ ] Журнал сварочных работ + реестр сварщиков (РД 03-615-03)

### Специфика по разделам

| Раздел | Дополнительно |
|---|---|
| **ВС** (питьевая) | Протокол бактериологического анализа воды |
| **ТС** (тепловые сети) | Акт о готовности теплоиспользующих установок |
| **ТХ** | Паспорт трубопровода (ГОСТ 32569) |
| **ТМ** | Акт индивидуального испытания оборудования |
| **ОВ** | Акт о пуске системы отопления в работу |

## 5. Быстрый поиск нормы

При запросе «какой допуск/норма для X» агент:
1. Определяет раздел (ВК / ОВ / ТС / ТМ / ТХ / ВС / ТК)
2. Находит документ в таблице раздела 1
3. Приводит конкретный допуск из раздела 2
4. Указывает метод контроля и форму документа из раздела 3–4
