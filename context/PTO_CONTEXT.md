## Правила работы с DWG — строго соблюдать

> Эти правила выведены из опыта работы. Нарушение любого из них приводит к ошибке.

1. **`ezdxf` не читает `.dwg`** — только `.dxf`. Для `.dwg` всегда использовать `accoreconsole`.

2. **Кириллица в путях ломает accoreconsole**. Путь `G:\Мой диск\Workspace\` содержит кириллицу.
   → **Обязательно**: копировать DWG в `C:\Temp\` перед обработкой, результат копировать обратно.

3. **`(load "файл.lsp")` заблокирован** в accoreconsole (политика безопасности).
   → AutoLISP писать **прямо в `.scr` файл** (inline), без отдельного `.lsp`.

4. **Вывод accoreconsole — UTF-16** (нулевые байты между символами).
   → При парсинге вывода: `$_ -replace [char]0,''`

5. **Формат SAVEAS** в SCR: указывать только имя файла без расширения, путь — только ASCII.

6. **Русская версия AutoCAD требует `_Y`** для подтверждения выхода (`_.QUIT` -> `_Y`). Голый `Y` отвергается русской локалью и приводит к зависанию.

7. **DXF-файлы только БЕЗ UTF-8 BOM**: писать через `[System.Text.UTF8Encoding]::new($false)`.

8. **Перед сохранением DWG через `_.SAVEAS` всегда удалять целевой файл в `C:\Temp`**: `Remove-Item "C:\Temp\output.dwg" -Force -ErrorAction SilentlyContinue`. Иначе AutoCAD выдаст запрос на подтверждение перезаписи («Файл уже существует. Заменить? <N>») и намертво зависнет в консоли.

9. **Перевод чертежа в белый цвет (монохром)**: использовать готовый скрипт:
   `& "C:\Users\User\.gemini\config\skills\pto-autocad-schemes\references\make_drawing_white.ps1" -FilePath "G:\Мой диск\Workspace\ЧЕРТЁЖ.dwg"`
   (Выполняет экспорт в DXF, сброс всех слоёв и объектов в цвет 7, удаление TrueColor 420/430 и очистку тегов `\C...;` в текстах за ~5 секунд).

## Стандартный шаблон обработки DWG (копируй без изменений)

```powershell
# ШАГ 1: Подготовка
New-Item -Path "C:\Temp" -ItemType Directory -Force | Out-Null
Copy-Item "G:\Мой диск\Workspace\ИСХОДНЫЙ.dwg" "C:\Temp\input.dwg" -Force

# ШАГ 2: Создать SCR-скрипт (inline LISP)
@'
; === ВАШ LISP КОД ЗДЕСЬ ===
_.SAVEAS
2018
C:\Temp\output
_.QUIT
_Y

'@ | Set-Content "C:\Temp\script.scr" -Encoding UTF8

# ШАГ 3: Запуск
$accore = "C:\Program Files\Autodesk\AutoCAD 2026\accoreconsole.exe"
& $accore /i "C:\Temp\input.dwg" /s "C:\Temp\script.scr" 2>&1 |
    Out-String | ForEach-Object { $_ -replace [char]0,'' }

# ШАГ 4: Вернуть результат
Copy-Item "C:\Temp\output.dwg" "G:\Мой диск\Workspace\РЕЗУЛЬТАТ.dwg" -Force
```
