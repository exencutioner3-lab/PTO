> **Полнофункциональный комплекс знаний, скиллов, AutoLISP-модулей и сценариев автоматизации для работы ИИ-ассистента Qwen Coder в качестве ведущего инженера производственно-технического отдела (ПТО) на строительных объектах РФ.**

Специализация — **трубопроводные инженерные разделы**:
- **ТХ** — Технологические трубопроводы
- **ВК** — Внутренний водопровод и канализация
- **ВС** — Водоснабжение и водоотведение (наружные сети)
- **ОВ** — Отопление, вентиляция и кондиционирование
- **ТК** — Тепловые камеры и конструкции теплосетей
- **ТМ** — Тепломеханические решения (котельные, ИТП, ЦТП)
- **ТС** — Тепловые сети (магистральные и внутриквартальные)

## 🚀 Возможности комплекса

- **Автоматическая пакетная обработка DWG** без запуска графического интерфейса AutoCAD через `accoreconsole.exe`.
- **Мгновенное обесцвечивание (монохром)**: перевод всех слоёв, объектов, штриховок и блоков в белый цвет (AutoCAD Color 7) с удалением TrueColor за ~5 секунд (`make_drawing_white.ps1`).
- **Комплексная очистка чертежей**: удаление размеров (DIMENSION), засечек (GT_1, Defpoints), выносок, текстов и штриховок.
- **Интеллектуальное редактирование таблиц `ACAD_TABLE`**: прямое заполнение ячеек в DXF с автоматической регенерацией геометрии AutoCAD (`update_acad_tables.ps1`).
- **Синхронизация схем по аналогии**: перенос правок, очистки и спецификаций с одной линии на другую (например, с Т1 на Т2/Т3).
- **Пакетная нормализация шрифтов ГОСТ**: замена отсутствующих шрифтов `CS_Gost2304.shx` и `Russia-GOST_Topo.shx` на стандартный `isocpeur.ttf` (`ISOCPEUR`) с очисткой повреждённых тегов `\f...;`.
- **Подсчёт объёмов и формирование ВОР**: расчёт точной длины трубопроводов по слоям, определение массы металла (ГОСТ 8732/10704), площади изоляции, количества стыков и арматуры.
- **Каталог фасонных элементов**: строительные длины и массы отводов, тройников, переходов и арматуры по ГОСТ для таблицы «Интервалы между стыковыми соединениями».

## 🛠️ Быстрый старт с Qwen Coder

### 1. VS Code + Cline / Roo Code
1. Установите расширение **Cline** или **Roo Code** в VS Code.
2. Откройте папку `qwen coder` как рабочую область (Workspace).
3. Расширение автоматически подхватит файл `.clinerules`.
4. В качестве модели выберите `Qwen 2.5 Coder 32B` (через Ollama, OpenRouter, LM Studio или DeepInfra).
5. Агент готов к выполнению инженерных команд!

### 2. Cursor IDE
1. Откройте проект в Cursor IDE.
2. Cursor автоматически применит корневой файл `.cursorrules` и `.cursor/rules/pto-engineer.mdc`.
3. В режиме Composer (Ctrl+I) выберите модель Qwen 2.5 Coder.

### 3. Ollama / LM Studio
Для запуска локальной модели создайте `Modelfile` в Ollama:

```dockerfile
FROM qwen2.5-coder:32b

# Подключение системного промпта
SYSTEM """
$(cat SYSTEM_PROMPT.md)
"""

PARAMETER temperature 0.2
PARAMETER top_p 0.95
```

Сборка и запуск:
```bash
ollama create pto-qwen -f Modelfile
ollama run pto-qwen
```

### 4. Aider CLI
```bash
aider --model ollama/qwen2.5-coder:32b --read SYSTEM_PROMPT.md
```

## ⚙️ Локальная среда и 12 правил обработки DWG

| Инструмент | Путь на машине | Примечания |
|---|---|---|
| **AutoCAD 2026** | `C:\Program Files\Autodesk\AutoCAD 2026\acad.exe` | Основная система |
| **accoreconsole** | `C:\Program Files\Autodesk\AutoCAD 2026\accoreconsole.exe` | Консольный запуск |
| **Рабочая папка** | `G:\Мой диск\Workspace\` | Путь с кириллицей |
| **Временная папка** | `C:\Temp\` | Исключительно ASCII |

### ⚠️ 12 Золотых правил (защита от зависаний)
1. **`ezdxf` не читает `.dwg`** — только `.dxf`. Для DWG использовать `accoreconsole`.
2. **Кириллица в путях ломает accoreconsole** — всегда копировать DWG в `C:\Temp\input.dwg`, обрабатывать там и возвращать результат.
3. **`(load "файл.lsp")` заблокирован** в консоли — писать AutoLISP код прямо в файл `.scr` (inline).
4. **Вывод accoreconsole — UTF-16** — в PowerShell парсить через `$_ -replace [char]0,''`.
5. **Формат SAVEAS в SCR** — указывать версию (например, `2018`), а имя файла — **без расширения `.dwg`**.
6. **Русская версия требует `_Y` при выходе** — `_.QUIT` -> `_Y` (голый `Y` зависает!).
7. **DXF только БЕЗ UTF-8 BOM** — писать через `[System.Text.UTF8Encoding]::new($false)`.
8. **Перед `_.SAVEAS` всегда удалять целевой файл в `C:\Temp\`** — `Remove-Item "C:\Temp\output.dwg" -Force`. Иначе появится запрос «Файл уже существует. Заменить? <N>» и консоль намертво зависнет.
9. **Никогда не вызывать `_.DXFIN` в SCR**, если файл открыт через параметр `/i "файл.dxf"`, иначе геометрия удвоится.
10. **`ACAD_TABLE` недоступен через ActiveX в консоли** — редактировать ячейки через прямой парсер DXF (Ветка E). Консоль сама регенерирует блок `*T...` со всеми координатами при следующем открытии.
11. **Удалять динамические поля (код 344)** перед записью статических значений в ячейки таблиц.
12. **Шрифты ГОСТ** заменять на `isocpeur.ttf` (`ISOCPEUR`) и очищать повреждённые теги `\f...;`.

## 🔀 Архитектура автоматизации (Ветки A–F)

### Ветка A: Удаление объектов чертежа (LISP inline)
Очистка от размеров, выносок, засечек или штриховок:
```powershell
New-Item -Path "C:\Temp" -ItemType Directory -Force | Out-Null
Copy-Item "G:\Мой диск\Workspace\СХЕМА.dwg" "C:\Temp\input.dwg" -Force
Remove-Item "C:\Temp\output.dwg" -Force -ErrorAction SilentlyContinue

@'
(progn
  (setq ss (ssget "X" '((0 . "DIMENSION")))) (if ss (command "_.ERASE" ss ""))
  (setq ss (ssget "X" '((0 . "LWPOLYLINE") (8 . "GT_1,Defpoints")))) (if ss (command "_.ERASE" ss ""))
  (setq ss (ssget "X" '((0 . "MTEXT") (8 . "0"))))
  (if ss (progn (setq i 0) (while (< i (sslength ss)) (setq e (ssname ss i)) (if (wcmatch (cdr (assoc 1 (entget e))) "*L=*") (entdel e)) (setq i (1+ i))))))
_.SAVEAS
2018
C:\Temp\output
_.QUIT
_Y

'@ | Set-Content "C:\Temp\clean.scr" -Encoding UTF8

& "C:\Program Files\Autodesk\AutoCAD 2026\accoreconsole.exe" /i "C:\Temp\input.dwg" /s "C:\Temp\clean.scr" 2>&1 | Out-Null
Copy-Item "C:\Temp\output.dwg" "G:\Мой диск\Workspace\СХЕМА.dwg" -Force
```

```powershell
# Экспорт в DXF, строковая замена UTF-8 без BOM и сборка DWG 2018
```

### Ветка E: Заполнение таблиц `ACAD_TABLE` и исправление шрифтов
Используется готовый скрипт:
```powershell
$updates = @{
    "8C468" = @{ 22 = "0,67"; 23 = "5,36" }
    "8D74F" = @{ 3 = "38"; 9 = "38"; 29 = "2870"; 31 = "3000" }
}
& "scripts\update_acad_tables.ps1" -InputDxf "C:\Temp\in.dxf" -OutputDxf "C:\Temp\out.dxf" -TableUpdates $updates
```

### Ветка F: Пакетный перевод чертежа в белый цвет (AutoCAD Color 7 / White)
Скрипт полностью обесцвечивает все слои чертежа, блоки, арматуру, штриховки и тексты, вычищает TrueColor (коды 420/430) и теги `\C...;` за 5 секунд:
```powershell
& "scripts\make_drawing_white.ps1" -FilePath "G:\Мой диск\Workspace\ЧЕРТЁЖ.dwg"
```

## 📐 Единый комплекс AutoLISP (`pto_tools.lsp`)

В папке `lisp/` размещён комплекс `pto_tools.lsp` (33 КБ). Основные команды:

| Команда | Описание |
|---|---|
| `СЛОИ-ПТО` | Создание полной номенклатуры слоёв ГОСТ (ТС, ТМ, ТК, ОВ, ВК, ВС, ТХ, ОСИ, РАЗМЕРЫ, ТЕКСТ, АРМАТУРА, ОПОРЫ, ИЗОЛЯЦИЯ, РАМКА) |
| `СЛОИ-ТС` (или `ТМ`, `ВК`...) | Создание слоёв для конкретного выбранного раздела |
| `ИСПРАВИТЬ-ШРИФТЫ` | Замена отсутствующих шрифтов на стандарт `isocpeur.ttf` (`ISOCPEUR`) |
| `РАМКА-ГОСТ` | Вставка стандартной рамки А1–А4 с отступами 20/5 мм и ГОСТ-штампом 185×55 мм |
| `ОЧИСТКА-РАЗМЕРОВ` | Комплексное удаление DIMENSION, засечек GT_1/Defpoints и меток `L=...` |
| `УДАЛИТЬ-ТЕКСТ` | Удаление текстовых примитивов с чертежа или выбранного слоя |
| `УДАЛИТЬ-ШТРИХОВКУ`| Удаление всех объектов штриховки (HATCH) |
| `СБРОС-ПОСЛОЮ` | Сброс цветов, весов и типов линий в ByLayer (включая объекты внутри блоков) |
| `ОБЕСЦВЕТИТЬ` | Перевод всех слоёв и примитивов в цвет 7 (White) |
| `ДЛИНА-ТРУБ` | Точный расчёт длины полилиний в мм и м с авторасчётом массы по ГОСТ 8732 |
| `ПОДЧЕТ-БЛОКОВ` | Автоматическая спецификация блоков арматуры, оборудования и опор |
| `ПОДЧЕТ-СТЫКОВ` | Подсчёт количества сварных стыков `ст.N` |
| `ОТВОД-ДУГА` | Радиусное сопряжение отвода по ГОСТ 17375 ($R = 1.5 D_y$) или ГОСТ 30753 |
| `СТЫК` / `СТЫК-НОМЕР`| Нанесение маркеров стыков (кружок + полка + текст) с автоинкрементом |
| `ПОЗИЦИЯ` | Выноска позиции спецификации в прямоугольной рамке `[N]` |
| `УКЛОН` | Стрелка уклона $i = ...$ вдоль линии трубопровода |
| `АРМАТУРА-ГОСТ` | Вставка условных графических обозначений (кран, задвижка, обратный клапан) |

## 📊 Нормативная база и спецификации

### Утверждённый стандарт формулировок итоговых строк:
- **Строка 1:** `Итого: монтаж трубопровода+фасонные изделия`
- **Строка 2:** `Итого: Общая протяженность участка линии`

### Строительные длины фасонных элементов (справочник `data/fittings_reference.md`):
- Отвод 90° Ду 50 ($57 \times 3.5$): $F = \mathbf{75}$ мм, масса = $\mathbf{0.67}$ кг
- Отвод 90° Ду 32 ($42.4 \times 2.6$): $F = \mathbf{38}$ мм, масса = $\mathbf{0.18}$ кг
- Отвод 90° Ду 25 ($33.7 \times 2.3$): $F = \mathbf{38}$ мм, масса = $\mathbf{0.11}$ кг
- Отвод 90° Ду 20 ($26.9 \times 2$): $F = \mathbf{29}$ мм, масса = $\mathbf{0.06}$ кг
- Отвод 90° Ду 15 ($21.3 \times 2$): $F = \mathbf{28}$ мм, масса = $\mathbf{0.04}$ кг
- Тройник равнопроходной Ду 50: $L = \mathbf{75}$ мм, масса = $\mathbf{1.60}$ кг
- Переход концентрический Ду 32×25: $L = \mathbf{51}$ мм, масса = $\mathbf{0.14}$ кг
- Опора трубопровода: масса = $\mathbf{2.28}$ кг
- Кран пробковый 3-ход. (под манометр G 1/2): масса = $\mathbf{0.20}$ кг
- Манометр технический (G 1/2 с трубкой Перкинса): масса = $\mathbf{0.25}$ кг
